# psychedelic-01 — Unicorn Viz effect pack

**Version 0.9.0**


Category pack of trippy, hypnotic procedural visuals for
[unicorn-viz](https://github.com/iDoMeteor/unicorn-viz).

## Effects
- **Plasma** — classic sin/cos colour-field
- **Kaleidoscope** — mirrored radial symmetry
- **Psychedelic** — neon palette-sine field

Each effect subclasses `unicornviz.effects.base.BaseEffect` and is auto-discovered.
